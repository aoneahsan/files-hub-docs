Endpoint reference

Base URL https://fileshub.zaions.com/api/v1, header X-API-Key: fh_live_…, JSON in and out. Every route needs a key with a password scope (own or admin) and the ability listed. Which entries a key reaches is explained in Access and scopes. The machine-readable version is in the OpenAPI document under the Passwords tag.

MethodPathAbilityPurpose
GET/passwordslistSearch and list entries
POST/passwordscreateSave a new entry
GET/passwords/{id}listOne entry's details
PATCH/passwords/{id}updateChange any field
POST/passwords/{id}/revealrevealThe password, current code and history
DELETE/passwords/{id}deleteTo Recently Deleted, or remove for good
POST/passwords/{id}/restoredeleteBack from Recently Deleted
POST/passwords/generatecreate or updateA strong password (stores nothing)
GET/passwords/securitylistWeak, reused, compromised and old passwords
POST/passwords/importcreateImport a CSV from iCloud Passwords, Chrome, Bitwarden or 1Password
GET/passwords/{id}/activitylistWho changed or revealed an entry, and when

The entry object​

Every answer except reveal and generate returns this shape. It never contains the password, the setup key or the history.

{
  "id": "01m5mjhqhzm44rckzkca0anxf0",
  "project_id": 1,
  "title": "Domain registrar",
  "websites": ["https://registrar.example.com", "https://registrar.example.com/login"],
  "username": "ops@acme.test",
  "notes": "Renews every March.",
  "tags": ["domains", "billing"],
  "is_favorite": true,
  "has_verification_code": true,
  "strength": { "score": 4, "label": "very strong" },
  "reused": false,
  "owner_scope": "admin",
  "created_via": "api",
  "password_changed_at": "2026-10-23T14:27:28+00:00",
  "last_revealed_at": null,
  "created_at": "2026-10-23T14:27:28+00:00",
  "updated_at": "2026-10-23T14:27:28+00:00",
  "deleted_at": null
}

Field meanings: Overview → What an entry holds. reused is null in lists and restore answers; ask for one entry to get it.

List​

GET /passwords — the entries this key can reach, favourites first, then by title.

QueryMeaning
qText in the title, username or websites.
websiteA host or URL; matches entries saved for that host (registrar.example.com).
tagEntries carrying this tag.
favorite1 for favourites only, 0 for the rest.
trashedonly lists Recently Deleted instead.
project_idEvery-project admin keys only: one project. Ignored for other keys.
page, per_pagePaging: default 20, maximum 50 (pagination).
curl -s "https://fileshub.zaions.com/api/v1/passwords?q=registrar&per_page=20" -H "X-API-Key: $FILESHUB_KEY"
{
  "success": true,
  "data": [ { "id": "01m5mjhqhzm44rckzkca0anxf0", "title": "Domain registrar", "...": "the entry object" } ],
  "meta": { "current_page": 1, "per_page": 20, "total": 1, "last_page": 1, "has_more": false, "next_page": null },
  "message": "Showing 1-1 of 1 (page 1 of 1). This is the last page."
}

Create​

POST /passwords → 201 with the entry.

Body fieldRules
kindlogin (default), wifi or note.
titleRequired. String, ≤ 191. For a Wi-Fi network, its name.
passwordRequired unless kind is note. String, ≤ 1,024.
wifi_securitywpa3, wpa2, wpa, wep or open (Wi-Fi networks).
websitesList of up to 20 strings (example.com, https://example.com/login).
usernameString, ≤ 191.
totp_secretBase32 setup key (at least 16 characters, spaces allowed) or an otpauth://totp/…?secret=… link.
notesString, ≤ 10,000.
tagsList of up to 20 strings, each ≤ 40.
is_favoriteBoolean.
project_idEvery-project admin keys only: store it in another project (its numeric id). Any other key may send only its own project's id.

The new entry's owner follows the key: an own key's entries are owner_scope: "own", an admin key's are "admin".

curl -s https://fileshub.zaions.com/api/v1/passwords \
  -H "X-API-Key: $FILESHUB_KEY" -H "Content-Type: application/json" \
  -d '{"title": "Domain registrar", "websites": ["registrar.example.com"], "username": "ops@acme.test", "password": "vKpqzt-mbw4hd-Xenfra"}'

Get​

GET /passwords/{id} → 200 with the entry, including reused.

Update​

PATCH /passwords/{id} → 200 with the entry. Send only what changes; every create field except project_id is accepted. Send "totp_secret": null to remove a setup key.

A new password moves the current one into the history (the last 10 are kept), re-scores the strength and sets password_changed_at. Sending the same password again changes nothing.

curl -s -X PATCH https://fileshub.zaions.com/api/v1/passwords/01m5mjhqhzm44rckzkca0anxf0 \
  -H "X-API-Key: $FILESHUB_KEY" -H "Content-Type: application/json" \
  -d '{"password": "Hqtrnw-5fmzky-pobcse", "tags": ["domains"]}'

Reveal​

POST /passwords/{id}/reveal → 200. Body (optional): {"history": true} adds the earlier passwords. Sets last_revealed_at and writes an audit-log row.

{
  "data": {
    "id": "01m5mjhqhzm44rckzkca0anxf0",
    "username": "ops@acme.test",
    "password": "Hqtrnw-5fmzky-pobcse",
    "unreadable": false,
    "verification_code": { "code": "626093", "expires_in": 21 },
    "password_history": [
      { "password": "vKpqzt-mbw4hd-Xenfra", "replaced_at": "2026-10-23T14:27:28+00:00" }
    ]
  }
}
  • verification_code is null when no setup key is stored. Codes are RFC 6238 codes: 6 digits every 30 seconds with SHA-1 unless the otpauth:// link named other digits, period or algorithm; expires_in is the seconds left. Ask again for the next one.
  • At most 30 reveals a minute per key; the 31st answers 429 with Retry-After.
  • password_history is null unless history was requested; newest first.
  • unreadable: true with password: null means the stored value can no longer be decrypted.

Delete​

DELETE /passwords/{id} → 200 {"data": {"id": "…", "deleted": true}}. The entry moves to Recently Deleted: it disappears from lists and lookups, and GET /passwords?trashed=only shows it.

DELETE /passwords/{id}?permanent=1 on an entry already in Recently Deleted removes it for good → 200 {"data": {"id": "…", "purged": true}}. On a live entry it answers 409 and changes nothing:

{ "message": "Delete the password first; only a deleted password can be removed for good." }

Restore​

POST /passwords/{id}/restore → 200 with the entry, back in place. Restoring a live entry is a no-op.

Security recommendations​

GET /passwords/security → 200. Counts the entries the key can reach (logins and Wi-Fi networks, never notes) in five groups, each with up to 50 ids. Every-project admin keys may add ?project_id=.

{
  "data": {
    "weak":        { "count": 1, "ids": ["01m5…"] },
    "reused":      { "count": 2, "ids": ["01m6…", "01m7…"] },
    "compromised": { "count": 1, "ids": ["01m6…"] },
    "old":         { "count": 0, "ids": [] },
    "not_checked": { "count": 3, "ids": ["01m5…", "01m7…", "01m8…"] }
  }
}

weak is a strength score of 0–1, reused shares a password with another entry in the same project, compromised appears in a known breach, old has not changed for a year, not_checked has not been checked for breaches yet (imports are checked by the nightly sweep).

Import​

POST /passwords/import → 201. Send the CSV your password app exports, as csv (text) or file (multipart, ≤ 2 MB). FilesHub reads the columns by name, so exports from iCloud Passwords, Chrome, Bitwarden and 1Password all work: title or name, URL, username, password, notes, OTPAuth or TOTP, tags or folder, favorite. Up to 1,000 rows. At most 10 imports a minute.

curl -X POST "$B/passwords/import" -H "X-API-Key: $KEY" -F "file=@Passwords.csv"
{ "data": { "created": 41, "skipped": 3, "invalid": 1, "ids": ["01m5…", "…"] } }

Entries are created exactly as POST /passwords would (owned by this key's scope, in its project). A row whose website and username already exist among the entries the key can reach is skipped; a row without a title (or website) or password is invalid. A CSV with no password column answers 422. 🔴 The export file holds every password in plain text: delete it from your computer once the import is done.

Activity​

GET /passwords/{id}/activity → 200, newest first, paginated (default 20, maximum 50). Every create, change, reveal, delete, restore and import that touched the entry, from the audit log:

{ "data": [ { "action": "password.revealed", "api_key_id": 77, "ip_address": "203.0.113.7",
              "details": { "scope": "admin", "history": false }, "at": "2026-10-24T09:12:03+00:00" } ] }

Entries in Recently Deleted keep their activity.

Generate​

POST /passwords/generate → 200. Stores nothing.

Body fieldMeaning
stylegrouped (default): three groups of six, one digit and one capital, like Fneuht-fguhgh-s3bitk. random: random characters.
lengthrandom only: 8–128, default 20.
symbols, numbers, uppercaserandom only: booleans, default true.
{ "data": { "password": "W4_zyv24KafLFlUu<zIo4epC", "strength": "very strong" } }

Errors​

Errors answer {"message": "…"}; validation errors add errors.

StatusWhenExample message
401No key, a wrong key or a disabled keyAPI key missing · Invalid API key · API key is inactive
402An external project with no plan for the password managerThis project has no active plan for passwords. See https://fileshub.zaions.com/pricing to request it.
403The key has no password scopeInsufficient permissions. Required scope: passwords
403The scope lacks the abilityThis key lacks the password ability: reveal.
403Creating in another project without every-project reachThis key can only store passwords in its own project.
404The id does not exist or the key cannot reach itNot found
409Permanent removal of a live entryDelete the password first; only a deleted password can be removed for good.
422Invalid inputThe password field is required. · The verification code setup key must be a base32 key or an otpauth:// link.
429The key's rate limit (default 60 requests a minute)See errors and limits
