# FilesHub pricing

FilesHub is priced per service: each API (file storage, email, email marketing and each developer
utility) has its own monthly price, and a project pays only for the services it uses.

The live price list, read from the same table the API enforces:

- Page: https://fileshub.zaions.com/pricing
- Markdown: https://fileshub.zaions.com/pricing.md

A call to a service your project has no plan for is refused with HTTP 402 naming the service.
